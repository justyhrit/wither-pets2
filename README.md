# Wither Pets: Cerberus & Pluto  (Fabric, Minecraft 26.2, Java 25)

Commands (each works for /cerberus, /pluto, or /allwi for both):
  spawn            summon the wither next to you (he follows you)
  follow           follow you
  stay             hold position (still shoots enemies)
  guard            wander/defend, never targets players
  come             teleport to you
  attack <player>  hunt that player
  say <message>    make him speak in chat
  status           health, mode, position
  dismiss          remove him

Build: put these files into a fresh project from https://fabricmc.net/develop
(or copy gradle wrapper from one), then run ./gradlew build.
Jar: build/libs/wither-pets-1.0.0.jar
